# Claude WP Bridge — Project Instructions

This file is auto-generated by the **Copy to AI** button in WP Admin > Claude Bridge.

When you install the plugin on your WordPress site, click "Copy to AI" to generate
a personalized version of this file with your real credentials, endpoints, and site details.

## Setup

1. Install and activate the Claude WP Bridge plugin on your WordPress site
2. Go to **WP Admin > Claude Bridge**
3. Click **Generate API Key**
4. Click **Copy to AI** — this generates a complete instruction set with:
   - Your site URL and API base
   - Your API key
   - All 18 available endpoints
   - WooCommerce status (if active)
   - Database prefix, theme, PHP/WP versions
   - Curl examples ready to paste
5. Paste the output into your Claude Code session or save it as `CLAUDE.md` in your project root

## Example CLAUDE.md (placeholder values)

```markdown
### Quick Test

curl -sk -H "Authorization: Bearer cwpb_your-api-key-here" https://your-site.com/wp-json/claude-bridge/v1/ping
```

## Important

- **Never commit real API keys** to a public repository
- Add `CLAUDE.md` to your `.gitignore` if it contains real credentials
- Rotate your API key in WP Admin > Claude Bridge if it is ever exposed
